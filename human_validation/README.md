# Human-validation materials

Public, blinded materials for the human-validation design (Methods 3.5).

Included:

- Annotation guidelines (`annotation_guidelines_zh.md`)
- Design and sampling manifests
- Blinded candidate / reference packets

Not included:

- Completed H1/H2 rating files
- Reviewer identities, private mapping keys, adjudication records, or individual comments

Aggregate reliability results are reported in the manuscript. Two reviewers used the same full-independent 604-record core package.
