# 双人人工审核任务说明（公开复现版）

版本：v2（2026-09-10）。本公开版保留正式评分规则和模块设计，不包含审核员身份、H1/H2回交评分、评论或任何身份映射。

## 1. 统一工作规则

两名审核员对同一批记录进行**全量独立盲评**。在完成初评前不得讨论具体样本或分数。审核时仅查看当前条目的任务要求、输入、reference/gold（如适用）与候选文本；不得查看模型身份、LLM-judge 分数或理由、另一名审核员的评分或模型排名。规则在评分前冻结；发现数据问题只在审核字段中记录，不直接修改 gold/reference。后续如有仲裁，必须另表保存，不覆盖原始独立评分。

历史材料中的“合规”只表示符合给定历史条款，不表示该条款在当代合理或应被推广。内容正确性与格式合规分别判断；非核心标点或轻微表面格式问题不能自动替代实质判断。

## 2. A：生成质量评分（180条/人）

三个生成任务各60条。每个任务四个维度，0–100分，可使用任意整数。通用锚点：100=充分满足；75=主要满足但有局部问题；50=部分满足且需实质修改；25=重大缺陷；0=完全不满足、方向相反或无有效可评文本。不要用流畅度补偿事实、逻辑或价值偏离。

### Story Generation
- 家风要义贴合度：核心要义是否通过关键行动、选择与后果体现，而非仅出现关键词或口号。
- 情节合理性：冲突、动机、因果、结局铺垫是否成立。
- 人物一致性：身份、关系、立场、动机和行为是否前后一致。
- 情感表达：情感是否来自具体行动和关系变化，避免空泛赞美和过度煽情。

### Text Rewriting
- 内容忠实度：保留对象、核心规范、条件、例外、因果和规范强度，不新增人物、史实、出处或义务。
- 目标风格契合度：整体语气、句式、节奏和组织方式符合指定传播风格，且不以失真换风格。
- 表达清晰度：语义、指代与句间关系清楚，避免病句、冗余和重复。
- 情感价值表达：自然传递原材料价值取向并保留历史语境，不把旧规包装成现代普遍强制义务。

### Story Continuation
- 家风要义贴合度。
- 前文衔接度：承接人物、关系、冲突、家风逻辑和时代/架空设定。
- 逻辑连贯性：续写内部因果成立，并核对“合理性说明”是否与正文一致。
- 表达清晰度。

生成审核另记录严重错误。严重错误包括：捏造具体史料/出处并当事实；把历史描述直接改成现代强制义务；关键主体、行为方向或因果发生实质反转。Text Rewriting 另记录“材料支持情况”。

## 3. B：benchmark/reference 质量审核

### QA（100条）
先独立判断三个陈述，再核对选项与拟定答案。审核答案唯一性、材料支持、历史—现代边界、干扰项有效性、文化任务适切性（1–5）、语言自然度（1–5）及最终结论（通过/修改/待核）。不得用 gold 反推材料。

### Relationship Identification（50条）
允许关系仅为父子、父女、母子、母女、祖孙、配偶、出嗣。父/母→子女，祖辈→孙辈；出嗣=[被过继者, 出嗣, 收嗣者]；配偶按原文顺序输出一次。同一记录只有一位明确配偶且随后明确“生子/生女”时，可唯一推出母亲；多配偶而生母不明时不得推断。禁止链式推出原文未写关系、补姓补名或用常识补造关系。

### Classification / Structuring（40+20条）
Classification 检查 gold 是否是最突出、最直接驱动关键选择的家风标签，以及是否存在实质缺陷或足以影响唯一 gold 的歧义。Structuring 检查前提条件、行为规范、主题类别是否均获原文支持，禁止新增对象、条件、理由或现代价值判断。

## 4. C：模型输出与 automatic scorer 审核

先判断完整回答的实质正确性，再分别记录必要 schema 错误、否定/范围理解错误、把历史旧规当现代义务、无依据的亲属关系，以及依据/抽取内容是否获原文支持。C_PLUS 对预先指定的 scoring endpoint 与完整回答分别判断；两者可以不同。

## 5. D：few-shot demonstration 审核

检查：属于目标任务、示例答案正确、示例格式合格、语义子类型合理（如提供）、是否存在可见误导。受控实验中的“故意错误示例”是实验操纵条件，不能与正确 reference demonstration 混为一类。

## 6. Reliability 分析原则

人—人一致性使用未经仲裁的两名审核员原始独立评分。Human–LLM 比较可按 Methods 使用两名审核员均值作为 human reference。不得用仲裁后的共识分替代原始 inter-rater reliability 数据。
